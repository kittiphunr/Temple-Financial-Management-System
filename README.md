# ระบบบัญชีรายรับ-รายจ่ายวัด (จังหวัดแพร่)

ระบบ PHP + MySQL สำหรับบันทึกบัญชีรายรับ-รายจ่ายของวัด จัดกลุ่มวัดตามอำเภอทั้ง 8 อำเภอของจังหวัดแพร่
(เมืองแพร่, ร้องกวาง, ลอง, สูงเม่น, เด่นชัย, สอง, วังชิ้น, หนองม่วงไข่)

## ความสามารถ
- บันทึก/แก้ไข/ลบ (soft delete) รายรับและรายจ่าย แยกหมวด ผูกกับวัด
- **แดชบอร์ดรายอำเภอ** (`dashboard.php`): การ์ดสถิติ รายรับรวม/รายจ่ายรวม/ยอดคงเหลือ/จำนวนวัด, กราฟรายเดือน, หมวดสูงสุด, ตารางวัดในอำเภอ (บอกวัดที่ยังไม่บันทึกบัญชี)
  แอดมินหลักเลือกอำเภอหรือทั้งจังหวัดได้ เจ้าหน้าที่อำเภอเห็นเฉพาะอำเภอตน แอดมินวัดเห็นเฉพาะวัดตน
- สรุปภาพรวมรายปี (พ.ศ.) รายเดือน รายหมวด รายวัด จัดกลุ่มตามอำเภอ
- พิมพ์รายงาน / บันทึกเป็น PDF ผ่านเบราว์เซอร์ และส่งออก CSV (เปิดด้วย Excel ได้)
- บทบาทผู้ใช้: `admin` แอดมินหลัก (ทุกวัด), `province` เจ้าคณะจังหวัด (ดูได้ทั้งจังหวัด อ่านอย่างเดียว), `district` แอดมินอำเภอ (เฉพาะอำเภอ), `temple` แอดมินวัด (เฉพาะวัดตนเอง)
- **โควตาผู้ใช้ระดับจังหวัด**: แอดมินอำเภอ (1 คน/อำเภอ) + แอดมินหลัก + เจ้าคณะจังหวัด = จำนวนอำเภอ + 2 (แพร่ 8 อำเภอ = **10 คน**) คำนวณจากตาราง `districts` จึงใช้กับจังหวัดอื่นได้เมื่อเปลี่ยนรายการอำเภอ — จัดการที่ จัดการระบบ → ผู้ใช้
- **โลโก้**: แอดมินวัดอัปโหลดโลโก้วัดที่ "ข้อมูลวัดของฉัน" (ระบบเตือนด้วยแบนเนอร์จนกว่าจะใส่); โลโก้อำเภอเป็นหน้าที่ของแอดมินหลักที่ จัดการระบบ → โลโก้อำเภอ ใช้เป็นหัวกระดาษและช่องลงนามในรายงาน/เอกสารพิมพ์
- **อนุโมทนาบัตร** (`receipt.php`, `receipts.php`): รายรับในหมวดรับบริจาคมีปุ่ม "อนุโมทนาบัตร" — กรอกชื่อ/ที่อยู่ผู้บริจาค ระบบออกเลขที่ต่อเนื่องรายวัดรายปี พ.ศ. (เล่มที่ X เลขที่ N/ปี) แปลงจำนวนเงินเป็นตัวอักษร ใส่หัวกระดาษ/โลโก้วัด เลขผู้เสียภาษีของวัด ช่องลงนามผู้รับเงินและเจ้าอาวาส และตราประทับ พิมพ์เป็น A4 ได้
  ออกได้เฉพาะแอดมินวัดนั้นและแอดมินหลัก (แอดมินอำเภอดูได้) ยกเลิกต้องระบุเหตุผลและเลขที่จะไม่ถูกนำกลับมาใช้ รายการที่ออกใบแล้วแก้/ลบไม่ได้จนกว่าจะยกเลิกใบ แอดมินหลักกำหนดหมวดรับบริจาคที่ จัดการระบบ → หมวดบัญชี
- **เอกสารที่พิมพ์ได้**: อนุโมทนาบัตร, รายงานสรุปรายปี/รายเดือน/รายหมวด/รายวัด, บัญชีรายรับ/รายจ่าย (หัวกระดาษ + ช่องลงนาม), แดชบอร์ด, ส่งออก CSV
- โลโก้ระบบและไอคอนเว็บ = ตราคณะสงฆ์จังหวัดแพร่ (`assets/img/logo.svg`)
- **บุคลากรวัด** (`people.php`): เจ้าอาวาส พระลูกวัด ไวยาวัจกร เพิ่มได้ไม่จำกัด พร้อมเลขบัตรประชาชน ที่อยู่ตามภูมิลำเนาเดิม รูปถ่าย เบอร์โทร
  - เลขบัตรประชาชนเข้ารหัส (libsodium) ตรวจหลักตรวจสอบ แสดงแบบปิดบัง ดูเลขเต็มได้เฉพาะแอดมินหลักและแอดมินวัดนั้น (บันทึก audit); แอดมินอำเภอ/เจ้าคณะจังหวัดเห็นเฉพาะข้อมูลที่ปิดบัง ไม่เห็นที่อยู่
  - รูปเก็บในฐานข้อมูล แปลงใหม่ด้วย GD (ตัด EXIF) และเสิร์ฟผ่าน `media.php` ที่ตรวจสิทธิ์เท่านั้น
  - ต้องติ๊กยืนยันว่าได้รับความยินยอมจากเจ้าของข้อมูล (PDPA) ก่อนเพิ่มบุคคล
- **ต้องสำรอง `storage/app.key`** (กุญแจเข้ารหัสเลขบัตร) ไว้ที่ปลอดภัย — ถ้าหาย เลขบัตรที่บันทึกไว้จะถอดรหัสไม่ได้ (หรือกำหนดเองผ่าน config `app_key` / env `TFMS_APP_KEY`) ต้องเปิดส่วนขยาย PHP `sodium`, `gd`, `fileinfo`
- ระบบจัดการ (`admin/`): วัด, นำเข้ารายชื่อวัด (Excel/CSV), ผู้ใช้, หมวดบัญชี, ประวัติการใช้งาน (audit log)
- **นำเข้าทะเบียนวัดจากไฟล์ Excel ใช้กับจังหวัดอื่นได้** (`admin/import.php`, แอดมินหลักเท่านั้น): อัปโหลดไฟล์ .xlsx รายงานทะเบียนวัดจาก [binfo.onab.go.th](https://binfo.onab.go.th/Temple/Temple-List-view.aspx) ได้ตรง ๆ ไม่ต้องแก้ไฟล์ — ระบบอ่านคอลัมน์จากหัวตาราง (รหัสวัด ชื่อวัด ประเภท นิกาย วันที่ตั้ง ตำบล อำเภอ จังหวัด รหัสไปรษณีย์ โทรศัพท์ อีเมล์ หมู่บ้าน เลขที่ หมู่ ซอย ถนน) มีหน้าตรวจสรุปก่อนบันทึก (วัดใหม่/อัปเดต/ข้าม/อำเภอ) แล้วจึงยืนยัน
  - ใช้เริ่มระบบในจังหวัดอื่น: ติดตั้งโดยติ๊กออก "นำเข้าทะเบียนวัดจังหวัดแพร่" → นำเข้า Excel ของจังหวัดนั้น → ระบบ **สร้างอำเภอ** (รหัสจากรหัสวัด) **ตั้งชื่อจังหวัดของระบบ** (หัวเอกสาร/รายงาน/ข้อความใต้ชื่อระบบ) และ **ลบอำเภอตัวอย่างของแพร่ที่ว่าง**; สร้างบัญชีแอดมินวัด 1 วัด 1 บัญชี; โควตาผู้ใช้ระดับจังหวัดปรับตามจำนวนอำเภอ (+2) เอง
  - ไม่ลบข้อมูลเดิม (วัดที่มีอยู่แล้วอัปเดตเฉพาะช่องที่ไฟล์มีค่า), อีเมลวัดนำเข้าเฉพาะเมื่อติ๊กและวัดนั้นยังไม่มีอีเมล, ปีที่ตั้งวัดเก็บตามไฟล์ (พ.ศ.), ต้องเปิดส่วนขยาย PHP `zip` (ไม่มีก็ใช้ CSV ได้); ตรา/โลโก้ระบบ (`assets/img/logo.svg`) เปลี่ยนเป็นของจังหวัดนั้นเอง
  - ยังต้องทำเองต่อ: ใส่โลโก้อำเภอ, สร้างแอดมินอำเภอ/เจ้าคณะจังหวัด, ลงอีเมลวัด, เปลี่ยน `assets/img/logo.svg` และข้อความในไฟล์ตั้งค่า (ถ้าต้องการ)
- **รายงานประจำเดือนตามแบบฟอร์มของวัด** (`statements.php`, ตามโฟลเดอร์ `ตัวอย่างเอกสาร/`): **แบบที่ 1** บัญชีรายรับ-รายจ่าย (เงินสด), **แบบที่ 2** บัญชีรายรับ-รายจ่าย (เงินฝากธนาคาร — 1 ตาราง = 1 บัญชี), **แบบที่ 3** รายงานเงินคงเหลือ ณ สิ้นเดือน (ตัวอักษรไทย) — เลือกวัด/เดือน/ปี พ.ศ. พิมพ์เป็น A4 (แบบ 1-2 แนวนอน, แบบ 3 แนวตั้ง) หรือบันทึกเป็น PDF มีช่องลงนามผู้จัดทำบัญชี (ไวยาวัจกร) และเจ้าอาวาสตามแบบ
  - ใช้ได้โดยกรอก **ยอดยกมา** ของเงินสดและบัญชีธนาคารแต่ละบัญชีที่หน้า **"ข้อมูลวัด"** (`profile.php` ส่วน "บัญชีของวัด" — แอดมินวัดกรอกเอง มีแบนเนอร์เตือนจนกว่าจะตั้งยอดยกมาเงินสด) หรือที่ `accounts.php` (ซึ่งมีส่วนโอน/ฝาก-ถอนระหว่างบัญชีด้วย) ระบบคำนวณยอดคงเหลือต่อให้ทุกเดือน
  - เลือก "บัญชี" (เงินสด หรือธนาคารใด) ทุกครั้งที่บันทึกรายรับ-รายจ่าย; การนำเงินสดฝากธนาคาร/ถอนเงิน บันทึกเป็น "โอน/ฝาก-ถอน" ซึ่งไปปรากฏเป็นรายจ่ายของบัญชีต้นทางและรายรับของบัญชีปลายทางในแบบที่ 1-2 แต่ **ไม่นับ** เป็นรายรับ-รายจ่ายของวัดในแดชบอร์ดและรายงานสรุป
  - ชุดทดสอบ `statements` ใช้ "โจทย์ตัวอย่าง" วัดสยามเทวา ม.ค.-ก.พ. 2568 แล้วตรวจว่าตัวเลขทุกช่องตรงกับเฉลยในแบบตัวอย่าง
- **ตรวจสอบใบอนุโมทนาด้วย QR code**: ทุกใบมี QR code มุมขวาบนและรหัสตรวจสอบ 16 ตัว (สุ่ม 80 บิต เดาไม่ได้) สแกนแล้วเปิดหน้าสาธารณะ `verify.php` ที่ไม่ต้องล็อกอิน แสดงว่าใบมีจริง วัด เลขที่ วันที่ จำนวนเงิน สถานะ (ใช้ได้/ยกเลิก) และชื่อผู้บริจาคแบบปิดบัง — ไม่แสดงที่อยู่ วัตถุประสงค์ หรือเหตุผลที่ยกเลิก ตั้ง `app_url` (config หรือ `TFMS_APP_URL` เช่น `https://wat.example.org/`) ให้ QR ชี้โดเมนสาธารณะ ถ้าไม่ตั้งจะใช้โดเมนที่ผู้ออกใบเปิดอยู่ (ไลบรารี `assets/vendor/qrcode.js` MIT อยู่ในระบบเอง)
- **อนุโมทนาบัตร** ใช้ฟอนต์ JS Chanok (`assets/fonts/`, ไฟล์ในระบบเอง ไม่พึ่งอินเทอร์เน็ต) ตัวเลขเป็นเลขไทย และพิมพ์เป็นกระดาษ **B5 แนวนอน** (เลือกขนาดกระดาษ B5 ในหน้าพิมพ์ของเบราว์เซอร์ถ้าเครื่องพิมพ์ไม่ตั้งตามอัตโนมัติ)
- **วันที่ทุกจุดเป็น พ.ศ.**: ฟอร์มกรอกวันที่เป็นช่องเลือก วัน/เดือน/ปี พ.ศ. (ไม่ใช้ `<input type="date">` ที่แสดงปีตามเบราว์เซอร์) ตรวจว่ามีวันนั้นจริง; หน้าจอ รายงาน ประวัติการใช้งาน และไฟล์ CSV ที่ส่งออกแสดงเป็น พ.ศ. ฐานข้อมูลเก็บเป็น ค.ศ. ภายใน (ฟังก์ชัน `date_be_field`, `date_be_parse`, `th_date` ใน `includes/bootstrap.php`)
- **การแจ้งเตือนด้วย SweetAlert2**: ข้อความสำเร็จเป็นป้ายมุมจอ ข้อผิดพลาดเป็นกล่องแจ้ง และกล่องยืนยันก่อนลบ/ดำเนินการ (`data-confirm` บนฟอร์มหรือปุ่ม) ไฟล์ไลบรารีอยู่ในเครื่อง (`assets/vendor/`, ไม่พึ่ง CDN) ไม่มี JavaScript ก็ยังเห็นข้อความเป็นแถบและฟอร์มส่งได้
- **หน้าต่าง "เกี่ยวกับระบบ · ผู้พัฒนา"** (ปุ่มท้ายทุกหน้า): หน่วยงาน ผู้พัฒนา ช่องทางติดต่อ และคำอธิบายระบบ แก้ข้อมูลที่ `includes/about.php`
- ความปลอดภัย: PDO prepared statements, CSRF token, `password_hash`, จำกัดสิทธิ์ตามขอบเขต, กัน CSV formula injection

## ติดตั้ง
ต้องการ PHP 8.1+ (ส่วนขยาย pdo_mysql, mbstring; แนะนำ openssl) และ MySQL 5.7+ / MariaDB 10.3+

### วิธีที่ 1: ตัวช่วยติดตั้งบนเว็บ (เหมือน WordPress)
วางโค้ดบนเว็บเซิร์ฟเวอร์ (Apache/Nginx + PHP-FPM, ใช้ HTTPS) ให้ผู้ใช้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์โปรเจกต์และ `storage/` ได้ชั่วคราว
แล้วเปิดเว็บไซต์ — ถ้ายังไม่ได้ติดตั้ง ระบบจะพาไปที่ `install.php` อัตโนมัติ ตัวช่วยพาทำทีละขั้น:

1. **ตรวจความพร้อม** — เวอร์ชัน PHP ส่วนขยาย สิทธิ์เขียนไฟล์ HTTPS
2. **ฐานข้อมูล** — โฮสต์/พอร์ต/ชื่อฐานข้อมูล/ผู้ใช้/รหัสผ่าน ทดสอบการเชื่อมต่อ สร้างฐานข้อมูลให้ถ้ายังไม่มี (ไม่เขียนทับฐานข้อมูลที่มีข้อมูลระบบอยู่แล้ว)
3. **จังหวัดที่ดูแลและข้อมูลเบื้องต้น** — (ก) เลือก **จังหวัด** จากรายการ 77 จังหวัด (ใช้ในหัวเอกสาร รายงาน อนุโมทนาบัตร) พร้อมชื่อระบบและคำอธิบายใต้ชื่อ (ข) **ทะเบียนวัด**: ใช้ชุดจังหวัดแพร่ 381 วัดที่มากับระบบ (เฉพาะแพร่) / **อัปโหลดไฟล์ Excel (.xlsx จาก binfo.onab.go.th) หรือ CSV ของจังหวัดนั้น** — ระบบสร้างอำเภอ วัด และตัดอำเภอตัวอย่างของแพร่ออกให้ (ตรวจว่าไฟล์เป็นของจังหวัดที่เลือก) / ยังไม่นำเข้า (ไปนำเข้าภายหลัง) พร้อมเลือกสร้างบัญชีวัดอัตโนมัติ (ค) ชื่อผู้ใช้/รหัสผ่านแอดมินหลัก (อย่างน้อย 10 ตัว มีตัวอักษรและตัวเลข)
4. **อีเมล** — ตั้งค่า SMTP พร้อมปุ่มส่งอีเมลทดสอบ (ใช้ส่งรหัสยืนยัน 2 ชั้นของวัด)
5. **ติดตั้ง** — สร้างตาราง นำเข้าข้อมูล สร้างบัญชี เขียน `config.local.php` (สิทธิ์ 0640) แล้วดาวน์โหลดรหัสผ่านเริ่มต้นของแต่ละวัดเป็น CSV **ได้ครั้งเดียว**

ติดตั้งเสร็จจะสร้าง `storage/installed.lock` ตัวช่วยจะใช้งานไม่ได้อีก (403) — แนะนำให้ลบ `install.php` ออกจากเซิร์ฟเวอร์ด้วย
ติดตั้งใหม่ได้โดยลบ `storage/installed.lock` และ `config.local.php` ด้วยตนเองเท่านั้น
ป้องกันคนอื่นเปิดตัวช่วยก่อนคุณ: ตั้งตัวแปรสภาพแวดล้อม `TFMS_INSTALL_KEY=รหัสลับ` ตัวช่วยจะถามรหัสนี้ก่อนเริ่ม
ระบบที่ติดตั้งไว้แล้วด้วยวิธีอื่น (มีผู้ใช้ในฐานข้อมูล) จะถูกตรวจพบว่าติดตั้งแล้วและไม่ถูกเปิดตัวช่วยซ้ำ

### วิธีที่ 2: บรรทัดคำสั่ง
```bash
# ตั้งค่าฐานข้อมูลผ่านตัวแปรสภาพแวดล้อม TFMS_DB_HOST/PORT/NAME/USER/PASS (หรือแก้ config.php)
php setup.php 'รหัสผ่านผู้ดูแลอย่างน้อย8ตัว'   # สร้างฐานข้อมูล ตาราง ข้อมูลตั้งต้น ทะเบียนวัด บัญชีวัด และผู้ใช้ admin
php -S 127.0.0.1:8080                            # ทดลองใช้งาน แล้วเปิด http://127.0.0.1:8080
```
หลังติดตั้งทั้งสองวิธี: ตั้งค่า SMTP (ถ้ายังไม่ได้ตั้ง) และลงอีเมลวัดที่ จัดการระบบ → บัญชีวัด
บนเซิร์ฟเวอร์จริงควรห้ามเข้าถึง `setup.php`, `sql/`, `data/`, `storage/`, `config.local.php` จากภายนอก (`setup.php` ทำงานได้เฉพาะ CLI)

## บัญชีวัดและการยืนยันตัวตนสองชั้น (2FA)
- **1 วัด = 1 บัญชี** สร้างอัตโนมัติตอนติดตั้ง (`php setup.php`), ตอนนำเข้ารายชื่อวัด และตอนเพิ่มวัดใหม่ — ฐานข้อมูลกันบัญชีที่ 2 ของวัดเดียวกันด้วย unique key
- **ชื่อผู้ใช้ถูกล็อก** ตั้งอัตโนมัติเป็น `wat` + รหัสวัด 11 หลัก (เช่น `wat03540118002`) ไม่มีหน้าจอใดแก้ชื่อผู้ใช้ได้ แม้แก้ชื่อวัดภายหลังก็ไม่เปลี่ยน
- **รหัสผ่านเริ่มต้นสุ่ม** ให้แอดมินหลักดาวน์โหลดเป็น CSV **ได้ครั้งเดียว** หลังสร้างบัญชี (ในฐานข้อมูลเก็บเฉพาะแฮช) —
  ตอนติดตั้งด้วย CLI จะเขียนไฟล์ `storage/temple_accounts_*.csv` (สิทธิ์ 0600) ให้นำไปแจกวัดแล้วลบทิ้ง
- **บังคับเปลี่ยนรหัสผ่านครั้งแรก:** แอดมินวัดที่เข้าสู่ระบบด้วยรหัสผ่านเริ่มต้นที่แอดมินหลักเตรียมไว้ให้ เมื่อผ่านรหัสยืนยันทางอีเมลแล้ว
  จะถูกพาไปหน้า "ตั้งรหัสผ่านใหม่" ทันที และใช้หน้าอื่นไม่ได้จนกว่าจะเปลี่ยน (ต้องไม่ซ้ำกับรหัสเริ่มต้นหรือชื่อผู้ใช้)
  การที่แอดมินหลักรีเซ็ตรหัสผ่านให้วัดก็บังคับเปลี่ยนอีกครั้งเช่นกัน
- **แอดมินวัดเปลี่ยนรหัสผ่านตัวเองได้** ที่เมนู "บัญชีของฉัน" (ต้องกรอกรหัสเดิม) แต่เปลี่ยนชื่อผู้ใช้และอีเมลไม่ได้
- **อีเมลวัด** แอดมินหลักเป็นคนสืบเสาะแล้วกรอกที่ จัดการระบบ → บัญชีวัด (กรอกทีละวัด หรือนำเข้า CSV `รหัสวัด,อีเมล`
  โดยดาวน์โหลดแม่แบบจากหน้าเดียวกัน) แก้ไขได้เฉพาะแอดมินหลัก
- **วัดที่ยังไม่มีอีเมลเข้าสู่ระบบไม่ได้** แม้รหัสผ่านถูก จนกว่าแอดมินหลักจะลงอีเมล
- **ล็อกอินสองชั้น (เฉพาะบัญชีวัด):** หลังรหัสผ่านถูก ระบบส่งรหัส 6 หลักไปอีเมลวัด ต้องกรอกก่อนเข้าระบบ
  รหัสใช้ได้ครั้งเดียว หมดอายุ 10 นาที กรอกผิดได้ 5 ครั้ง ขอรหัสใหม่ได้ทุก 60 วินาที (สูงสุด 5 ครั้ง/30 นาที) เก็บเฉพาะค่าแฮช
  การเปลี่ยนหรือลบอีเมลทำให้รหัสที่ค้างอยู่ใช้ไม่ได้ทันที
- รหัสผ่านผิดครบ 5 ครั้ง บัญชีถูกล็อก 15 นาที (แอดมินหลักรีเซ็ตรหัสผ่านเพื่อปลดล็อกได้)
- **แอดมินหลัก แอดมินอำเภอ และเจ้าคณะจังหวัด ก็ต้องยืนยันรหัส 6 หลักทางอีเมลเช่นกัน** (ค่าเริ่มต้นเปิด):
  - แอดมินหลัก: ครั้งแรกหลังติดตั้ง/อัปเกรด ระบบให้ลงทะเบียนอีเมลและยืนยันด้วยรหัสก่อนเข้าระบบ เปลี่ยนอีเมลภายหลังที่ "บัญชีของฉัน" (ต้องใส่รหัสผ่านและยืนยันรหัสที่อีเมลใหม่)
  - แอดมินอำเภอ/เจ้าคณะจังหวัด: แอดมินหลักลงอีเมลให้ที่ จัดการระบบ → ผู้ใช้ (ไม่มีอีเมล = เข้าระบบไม่ได้)
  - ปิดได้เฉพาะกรณีฉุกเฉิน (เช่น ตั้ง SMTP ไม่ได้ ทำให้แอดมินเข้าระบบไม่ได้): `'staff_2fa' => false` ใน `config.local.php` หรือ `TFMS_STAFF_2FA=0` — แล้วรีบแก้ SMTP และเปิดกลับ
  - แอดมินหลักเสียอีเมล (เข้าอีเมลเดิมไม่ได้): ให้ผู้ดูแลเซิร์ฟเวอร์รัน `UPDATE users SET email = NULL, email_verified_at = NULL WHERE username = 'admin';` แล้วเข้าสู่ระบบเพื่อลงทะเบียนอีเมลใหม่
- **ลืมรหัสผ่าน** (`forgot.php` → `reset.php`): กรอกชื่อผู้ใช้ ระบบส่งรหัส 8 หลักไปที่อีเมลที่ลงทะเบียนไว้ (บัญชีวัด = อีเมลวัด) ใช้ได้ครั้งเดียว หมดอายุ 15 นาที ผิดได้ 5 ครั้ง ตอบเหมือนกันไม่ว่ามีชื่อผู้ใช้นี้หรือไม่ และกู้รหัสสำเร็จจะปลดล็อกบัญชีที่ถูกล็อกด้วย บัญชีที่ไม่มีอีเมลให้ติดต่อแอดมินหลักรีเซ็ตให้

### ตั้งค่าการส่งอีเมล
ตั้งตัวแปรสภาพแวดล้อม (หรือแก้ `config.php`) — ถ้าไม่ตั้ง SMTP วัดจะขอรหัสไม่ได้และเข้าสู่ระบบไม่ได้

```bash
TFMS_MAIL_DRIVER=smtp          # smtp | mail (PHP mail()) | log (ทดสอบเท่านั้น เขียน storage/mail.log)
TFMS_SMTP_HOST=smtp.example.org
TFMS_SMTP_PORT=587
TFMS_SMTP_SECURE=tls           # tls (STARTTLS) | ssl | none
TFMS_SMTP_USER=...  TFMS_SMTP_PASS=...
TFMS_MAIL_FROM=no-reply@your-domain.org
```
อย่าใช้ driver `log` บนเซิร์ฟเวอร์จริง (รหัส 2FA จะถูกเขียนลงไฟล์) และบนเว็บเซิร์ฟเวอร์ต้องห้ามเข้าถึง `storage/`
(มี `.htaccess` สำหรับ Apache แล้ว; Nginx ให้ `deny all` เอง)

## การจัดหน้า (Tailwind CSS)


ธีมสี `brand` (แดง) และ `gold` (ทอง) กำหนดใน `tailwind.config.js` ฟอนต์ Sarabun โหลดจาก Google Fonts

## ข้อมูลวัดจังหวัดแพร่
`setup.php` โหลดทะเบียนวัดจริง 381 วัด จาก `data/temples_phrae.csv` (แปลงจาก `Report_Temple.xlsx`
ทะเบียนวัดของสำนักงานพระพุทธศาสนา) พร้อมตำบล หมู่ที่ รหัสวัด 11 หลัก ประเภทวัด และนิกาย ทุกวัดมีสถานะ "ตรวจสอบแล้ว"

| อำเภอ | วัด | อำเภอ | วัด |
|---|---|---|---|
| เมืองแพร่ | 95 | สอง | 40 |
| ลอง | 60 | เด่นชัย | 31 |
| วังชิ้น | 52 | หนองม่วงไข่ | 9 |
| สูงเม่น | 48 | ร้องกวาง | 46 |

- ชื่อวัดในไฟล์ต้นฉบับไม่มีคำว่า "วัด" นำหน้า สคริปต์แปลงจึงเติมให้
- วัดที่ชื่อซ้ำกันแยกด้วยรหัสวัด/ตำบล (เช่น "วัดน้ำชำ" มี 2 แห่งในอำเภอเมืองแพร่)
- ไฟล์ต้นฉบับมีรายการที่ถูกแก้ไขชื่อ/ที่ตั้งในคอลัมน์หมายเหตุ (เช่น โปร่งศรี → โป่งศรี) ซึ่งช่องชื่อวัดเป็นชื่อล่าสุดแล้ว
- อัปเดตทะเบียนภายหลังได้ที่ จัดการระบบ → นำเข้ารายชื่อวัด หรือสร้าง CSV ใหม่ด้วย
  `python3 tools/build_temples_csv.py Report_Temple.xlsx data/temples_phrae.csv`
- ข้อมูลเจ้าอาวาสและโทรศัพท์ไม่มีในทะเบียน แก้ไขได้ที่ จัดการระบบ → จัดการวัด
