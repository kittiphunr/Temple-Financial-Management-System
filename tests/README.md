# ชุดทดสอบ

ทดสอบระบบแบบ end-to-end ผ่าน HTTP จริง (`php -S`) กับฐานข้อมูลจริง และเซิร์ฟเวอร์ SMTP ปลอมที่อยู่ในตัวชุดทดสอบเอง
ใช้เฉพาะไลบรารีมาตรฐานของ Python ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## วิธีรัน
```bash
# ต้องมี: python3, PHP 8.1+ (CLI + pdo_mysql) และ MySQL/MariaDB ที่เชื่อมต่อได้ด้วยบัญชีที่สร้าง/ลบฐานข้อมูลได้
export TFMS_TEST_DB_HOST=127.0.0.1 TFMS_TEST_DB_PORT=3306   # ค่าเริ่มต้น
export TFMS_TEST_DB_USER=root      TFMS_TEST_DB_PASS=...    # บัญชีที่มีสิทธิ์ CREATE/DROP DATABASE

python3 tests/run_all.py              # ทุกชุด (ใช้เวลาราว 1 นาที)
python3 tests/run_all.py features     # เฉพาะชุดฟีเจอร์หลัก
python3 tests/run_all.py install      # เฉพาะตัวช่วยติดตั้ง + บังคับเปลี่ยนรหัสผ่าน
python3 tests/run_all.py people       # เฉพาะโลโก้ / บุคลากร / โควตาผู้ใช้
```
รหัสออก: `0` ผ่านทั้งหมด · `1` มีข้อที่ไม่ผ่าน · `2` เชื่อมต่อฐานข้อมูลไม่ได้/ระบุชุดทดสอบผิด

## ความปลอดภัยของการทดสอบ
- รันบน **สำเนาโปรเจกต์ในโฟลเดอร์ชั่วคราว** (ไม่แตะ `config.local.php`, `storage/`, ไฟล์จริงของคุณ)
- ใช้ฐานข้อมูลชื่อสุ่ม `tfms_test_<สุ่ม>_*` และลบทิ้งทั้งหมดเมื่อจบ (แม้ทดสอบล้ม)
- เซิร์ฟเวอร์ SMTP ปลอมรับอีเมลในโปรเซส ไม่มีการส่งอีเมลออกภายนอก
- ตรวจ log ของ PHP ด้วย: มี Warning/Notice/Fatal/Deprecated ข้อใดข้อหนึ่ง = ไม่ผ่าน

## สิ่งที่ครอบคลุม
**features** (ติดตั้งด้วย `setup.php`): 1 วัด 1 บัญชี (unique), วัดที่ไม่มีอีเมลเข้าไม่ได้, แอดมินหลักลง/แก้/นำเข้าอีเมล, 2FA (รหัสผิด/ซ้ำ/หมดอายุ/ผิดครบ 5 ครั้ง/ขอใหม่เร็วเกินไป),
SMTP client (AUTH, UTF-8), ล็อกบัญชีเมื่อรหัสผ่านผิด 5 ครั้ง, เปลี่ยนรหัสผ่าน, ชื่อผู้ใช้/อีเมลแก้เองไม่ได้, สิทธิ์ (แอดมินวัดเข้า admin ไม่ได้),
วัดใหม่ได้บัญชีอัตโนมัติ, การตรวจพบ "ติดตั้งแล้ว" (มี/ไม่มีไฟล์ล็อก)

**install**: ตัวช่วยติดตั้งทุกขั้นและกรณีผิดพลาด (รหัสผ่านฐานข้อมูลผิด, ฐานข้อมูลที่มีข้อมูลอยู่แล้ว, รหัสแอดมินอ่อน, SMTP ผิด, CSRF), `TFMS_INSTALL_KEY`,
การล็อกหลังติดตั้ง (403), สิทธิ์ `config.local.php` 0640, CSV รหัสผ่านเริ่มต้นดาวน์โหลดได้ครั้งเดียว, และการบังคับเปลี่ยนรหัสผ่านครั้งแรกทุกกรณี

**people**: อัปโหลดโลโก้วัด/อำเภอ (ปฏิเสธไฟล์ไม่ใช่ภาพ/ใหญ่เกิน, แปลงใหม่ตัด payload), โควตาผู้ใช้ = อำเภอ+2 และ 1 คนต่ออำเภอ, สิทธิ์ดู/แก้/เปิดเลขบัตร (แอดมินอำเภอ/เจ้าคณะดูเลขเต็มไม่ได้), เลขบัตรเข้ารหัสในฐานข้อมูล+ตรวจหลักตรวจสอบ+ห้ามซ้ำ, เจ้าอาวาสได้คนเดียว, รูป/เอกสารเข้าถึงผ่าน media.php ตามสิทธิ์, หัวกระดาษรายงาน

## ข้อจำกัด (ยังไม่ครอบคลุม)
- SMTP แบบเข้ารหัส (STARTTLS/SSL) — เซิร์ฟเวอร์ปลอมรองรับเฉพาะแบบไม่เข้ารหัส ต้องทดสอบกับ SMTP จริงด้วยปุ่ม "ส่งอีเมลทดสอบ" ในตัวช่วยติดตั้ง
- Migration กับฐานข้อมูลรุ่นเก่า (`sql/migrations/`) — ทดสอบด้วยมือ
- หน้าตา/เลย์เอาต์ (ตรวจด้วยตาในเบราว์เซอร์)
- ไม่ได้ผูกกับ CI; ถ้าจะรันใน CI ให้มีบริการ MySQL/MariaDB และตั้งตัวแปร `TFMS_TEST_DB_*`
